DonutMatch автоматизирует подготовку и проведение матчей на сервере Counter-Strike: Source. Игроки отмечают готовность, команды собираются, матч проходит свои игровые фазы, а счёт и события сохраняются для истории.

Установка
DonutMatch.

Подготовьте файлы плагина на сервере и перезапустите его, чтобы начать матч.

  1. 01

    Установите плагин

    Поместите предоставленный donut_match.smx в addons/sourcemod/plugins/.

  2. 02

    Добавьте зависимости

    Установите необходимые runtime-зависимости, перечисленные в README проекта.

  3. 03

    Скопируйте файл переводов

    Поместите donut_match.phrases.txt в addons/sourcemod/translations/.

  4. 04

    Разместите конфиги фаз

    Скопируйте конфиги в каталог cfg/donutmatch/.

  5. 05

    Перезапустите и проверьте

    Перезапустите плагин или сервер и проверьте журнал SourceMod.
